## HOSPITALITY-ANALYSIS-DATA
This project focuses on performing a comprehensive analysis of hotel performance for AtliQ Hospitality, a leading hotel chain with properties spread across multiple Indian cities.
The goal of this project is to analyze hotel performance data and build interactive dashboards that help the management track key performance indicators (KPIs) such as revenue, occupancy, cancellations, property performance, and booking patterns. These dashboards enable decision-makers to quickly identify trends, monitor performance across different locations, and improve overall operational efficiency.

The data provided by the client was scattered across multiple sources, including booking records, customer datasets, and property-level information. As a Data Analyst, I integrated all datasets, performed data cleaning, standardized formats, eliminated duplicates, and built interactive dashboards using Excel, Power BI, and Tableau. The final insights provided actionable recommendations to improve occupancy and optimize revenue.

## Objectives

Track and monitor hotel performance metrics

Analyze revenue, occupancy, and booking trends

Identify top-performing and underperforming properties

Study city-wise performance and customer behavior

Provide actionable insights for strategic decision-making

## Tools & Technologies Used

Power BI – interactive dashboards, DAX measures

Tableau – visual analytics, trend charts

Excel – data cleaning, pivot reporting

MySQL – data extraction, joins, indexing

## Challenges

Data inconsistencies across multiple sources

Null values, duplicate bookings, and date/time formatting issues

Performance issues in dashboards due to large datasets

Designing dashboards that work on both desktop and mobile

## Solutions Implemented

Standardized data formats and cleaned missing/duplicate values

Used optimized SQL queries with joins and indexing

Designed dashboards with slicers, filters, and KPIs

Validated results using cross-tool comparison

## Key Insights

Total Revenue: ₹1.71B | Total Bookings: 134K+

Occupancy Rate: ~58% | Cancellation Rate: ~25%

Top City: Mumbai (highest revenue & ADR)

Top Hotels: AtliQ Exotica & AtliQ Palace

Elite & Premium rooms generate majority revenue

Weekday bookings higher → strong corporate demand

## Conclusion

This project demonstrates how data analytics, when combined with visualization tools like Power BI, Excel, Tableau, and SQL, can help transform hospitality data into meaningful insights. The solution empowers management to make informed decisions, improve guest satisfaction, and enhance revenue performance.
